# Scroll Motion Designer

## Principles

- Motion follows storytelling.
- Every animation has a purpose.
- Use GSAP ScrollTrigger.
- Prefer timeline over scattered animations.
- Maximum 3 simultaneous moving elements.
- Ease: power2.out, power3.out.
- Avoid unnecessary parallax.
- Create rhythm with spacing.
- Build anticipation before reveals.
- Respect reduced-motion preference.
- Mobile animation should be simplified.
- Keep 60fps.
